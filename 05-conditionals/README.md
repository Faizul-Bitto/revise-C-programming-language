# Conditionals in C

## Overview

This section covers conditional statements in C programming. Conditionals allow your program to make decisions and execute different code blocks based on whether certain conditions are true or false. This is fundamental to creating programs that can respond differently to different situations.

## Topics Covered

- **if-else Statements**: Basic decision-making structures
- **if-else Ladder**: Multiple conditions checked in sequence
- **Nested if-else**: Conditionals within conditionals for complex decision-making

## What You'll Learn

- Making decisions based on conditions
- Executing different code blocks for different scenarios
- Handling multiple conditions sequentially
- Nesting conditional statements for complex logic
- Understanding program flow control with conditionals
- Best practices for writing clear and readable conditional code

## Key Concepts

### Basic if-else

```c
if (condition) {
    // Code executes if condition is true
} else {
    // Code executes if condition is false
}
```

### if-else Ladder

```c
if (condition1) {
    // Code for condition1
} else if (condition2) {
    // Code for condition2
} else {
    // Default code
}
```

### Nested if-else

```c
if (condition1) {
    if (condition2) {
        // Code when both conditions are true
    }
}
```
