# Variables in C

## Overview

This section covers the fundamental concept of variables in C programming. Variables are containers that store data values in memory. Understanding how to declare, initialize, and use variables is essential for any C program.

## Topics Covered

- **Variable Declaration and Initialization**: Learning how to declare variables of different data types and initialize them with values
- **Printing Variables**: Understanding how to display variable values using format specifiers with `printf()`

## What You'll Learn

- Different data types in C (int, float, char, double)
- How to declare variables with appropriate data types
- Variable naming conventions and rules
- How to initialize variables during declaration or separately
- Using format specifiers to print different data types
- Understanding variable scope and memory allocation

## Key Concepts

### Data Types

- **int**: Stores integer values (e.g., 10, -5, 0)
- **float**: Stores floating-point numbers (e.g., 3.14, -2.5)
- **char**: Stores single characters (e.g., 'A', 'z', '5')
- **double**: Stores double-precision floating-point numbers

### Variable Declaration

```c
int age;
float price;
char grade;
```

### Variable Initialization

```c
int age = 25;
float price = 99.99;
char grade = 'A';
```
