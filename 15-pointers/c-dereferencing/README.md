# Dereferencing

## Overview

As we know, we can store one variable's memory address in another variable, which we call pointer variable. We can also manipulate that variable with that pointer variable, which is called dereferencing.

## Topics Covered

- **Printing Value from Pointer Variable**: Getting the value stored at the address using the dereference operator `*`
- **Changing Value from Pointer Variable**: Modifying the value at the address using the dereference operator `*`

## What You'll Learn

- Understanding dereferencing concept
- Using `*` operator to access value at address
- Getting value from pointer variable
- Modifying value through pointer variable
- Understanding reference vs dereference
