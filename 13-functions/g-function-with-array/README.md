# Function with Array

## Overview

This section covers functions that work with arrays in C. When arrays are passed to functions, they are passed by reference, meaning changes made to the array inside the function affect the original array.

## Topics Covered

- **Passing Array in Function**: Passing arrays to functions and modifying them
- **Array Input and Print**: Getting array input from user and printing using functions

## What You'll Learn

- How to pass arrays to functions
- Understanding array parameter syntax
- How arrays are passed by reference
- Modifying arrays inside functions
- Getting array input and processing it in functions
